# sysenv

sysenv在线教程在新窗口打开

提示

查看当前 JVM 的环境属性(System Environment Variables)

# 使用参考

 USAGE:
   sysenv [-h] [env-name]

 SUMMARY:
   Display the system env.

 EXAMPLES:
   sysenv
   sysenv USER

 WIKI:
   https://arthas.aliyun.com/doc/sysenv

 OPTIONS:
 -h, --help                                                 this help
 <env-name>                                                 env name
