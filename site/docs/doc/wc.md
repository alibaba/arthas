# wc

通过管道统计命令输出的行数。目前只支持行数统计，不支持单词数、字节数统计或直接读取文件。

## 参数说明

| 参数            | 说明                                     |
| --------------- | ---------------------------------------- |
| `-l`、`--lines` | 统计输出行数，使用管道时需要指定         |
| `-h`、`--help`  | 单独执行 `wc -h` 或 `wc --help` 查看帮助 |

## 使用示例

统计输出行数：

```text
$ echo 'hello' | wc -l
1
```

使用长参数，统计过滤后的输出：

```bash
sysprop | grep java | wc --lines
```

统计线程命令的输出：

```bash
thread | wc -l
```

`wc` 统计的是文本输出，表头和分隔线也会影响结果，因此结果不等于线程数、类数量或方法调用次数。统计结果在上游命令结束后输出；对于 `watch` 等持续输出的命令，可以用上游命令的 `-n` 参数限制执行次数。

::: warning
当前对空行、末尾没有换行的文本等情况的计数可能与系统的 `wc -l` 不同。
:::

## 查看帮助

查看帮助时，单独执行以下命令，不放在管道右侧：

```bash
help wc
wc --help
```

单独执行 `wc` 或 `wc -l` 不会读取标准输入，而是提示使用管道。
